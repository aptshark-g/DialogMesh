## 1. 系统定位

### 1.1 不是什么

| 不是 | 原因 |
|------|------|
| **Agent** | 不执行任务，不与环境交互闭环；任务是"生产知识"而非"完成目标" |
| **知识库** | 不是静态存储；知识会遗忘、会退化、会被质疑 |
| **RAG** | 不是检索-生成管道；没有预设的知识边界 |
| **推理引擎** | 不做前向/后向链式推理；做"结构性发现"与"公理化凝练" |

### 1.2 是什么

> **认知智流**是一个**长期自组织的认知基础设施**，核心使命是：从持续摄入的信息流中，通过显性化的结构化过程，凝练出可验证的公理化知识，并持续自我修正。

三个关键特征：

1. **显性化**：所有决策、推理、假设、验证过程全审计、可追溯
2. **自指修正**：系统能对自身的规则、决策、知识结构进行决策
3. **公理化演化**：知识不是平等存储的，而是分层（软编码/硬编码）且有支撑性等级的

### 1.3 类比

| 类比 | 对应关系 | 差异 |
|------|----------|------|
| **免疫系统** | CL0硬编码=中枢耐受，软编码=外周耐受，Razor=克隆删除 | 免疫系统无"元认知" |
| **判例法** | 硬编码=宪法，软编码=判例，MCT=判例树 | 法律无自动验证机制 |
| **科学方法** | 假设→实验→证伪→修正 | 自动化+无人类偏见 |
| **遗传编程** | 决策树分叉=染色体变异，Razor=选择压力 | 适应度函数是支撑性而非外部评分 |

## 2. 核心架构

### 2.1 五层架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        应用层（可选）                             │
│          Obsidian导出 / 可视化 / API查询 / 人工审查界面             │
├─────────────────────────────────────────────────────────────────┤
│  L5 元认知层（Meta-Cognitive Layer）                              │
│  ├── MetaCognitiveArbiter（发散/收敛/视角仲裁）                    │
│  ├── MetaAuditor（五类审计：深度/置信度/循环/覆盖率/时效）          │
│  └── MCT（元认知决策树：分叉/回溯/合并/复活/剪枝）                 │
├─────────────────────────────────────────────────────────────────┤
│  CL 控制流层（Control Layer）                                    │
│  ├── CL0 硬约束（宪法层：零LLM参与，失败阻断）                     │
│  ├── CL1 近迁移反思（历史案例检索+局部一致性）                     │
│  ├── CL2 远迁移思考（跨域类比+CSM结构匹配）                        │
│  ├── CL3 质疑层（公理化验证+矛盾检测+风险评估）                    │
│  └── CL4 协调层（算力比例分配+决策仲裁+调度）                      │
├─────────────────────────────────────────────────────────────────┤
│  校准层（Calibration Layer）                                     │
│  ├── CalibrationExecutor（假设→形式化→仿真验证）                   │
│  ├── BackendRegistry（MATLAB/Python/Unity/...插件化后端）          │
│  └── MCTCalibrationBridge（结果回填→决策树→触发重评估）            │
├─────────────────────────────────────────────────────────────────┤
│  L0-L4 认知层（Cognitive Processing）                             │
│  ├── L0 原始文本摄入                                             │
│  ├── L1 预过滤（负知识库+关键词+语义向量）                         │
│  ├── L2 结构化（键合图元解析+元角色注册表）                        │
│  ├── L3 形式化转译（LLM动态判断+原生形式化语言）                    │
│  └── L4 双向假设（正向演绎+逆向搜索+伪命题复活）                    │
├─────────────────────────────────────────────────────────────────┤
│  持久化层（Persistence）                                         │
│  ├── 事实断言层（SQLite：100%可信，图结构）                        │
│  ├── 假设推演层（SQLite：条件化+置信度）                           │
│  ├── MCT决策树（SQLite：分叉/回溯/支撑边/版本）                    │
│  └── 负知识缓存（Bloom Filter + LRU + SQLite）                    │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 横向贯穿层

| 贯穿层 | 功能 | 位置 |
--------|------|------|
| **支撑性追踪** | 计算S(D)，标记骨架/支撑/边缘 | 横跨 L5 + CL + MCT |
| **激活度系统** | ACT-R双权重（频率+时间衰减） | 横跨 L2-L4 |
| **遗忘机制** | Limbo Zone + 概念退化 + 归档 | 横跨持久化层 |
| **算力协调** | CL4比例分配（非跷跷板） | 横跨 CL0-CL4 |

## 3. 数据流全景

### 3.1 主流程：信息摄入 → 公理化

```
文献/数据/观测
    ↓
[L0] 原始文本摄入
    ↓
[L1] 预过滤
    ├── 负知识库检查（Bloom Filter快速排除）
    └── 语义向量初筛（sentence-transformers）
    ↓
[L2] 结构化解构
    ├── 键合图元解析（YAML驱动）
    └── 元角色对齐（JUNCTION/TRANSFORM/SOURCE等）
    ↓
[L3] 形式化转译
    ├── LLM动态判断（可变结构，非固定五元组）
    └── 原生形式化语言生成（ODE/传递函数/状态空间）
    ↓
[L4] 双向假设引擎
    ├── 正向演绎（Horn子集规则引擎）
    └── 逆向搜索（Bi-BFS + 伪命题复活）
    ↓
[CL0] 硬约束验证
    ├── 字段完整性 / 环检测 / 量纲一致性
    └── 结构签名一致性
    └── ❌ 失败 → BLOCK，记录决策节点
    ↓
[CL1] 近迁移反思
    ├── 历史案例检索（SQLite+向量混合）
    └── 局部一致性检查
    ↓
[CL2] 远迁移思考
    ├── CSM三层匹配（结构+角色+语义）
    ├── WL子树同构测试（VF2算法）
    └── 硬闸门：锚点数<3 → 强制降级CL1
    ↓
[CL3] 质疑层
    ├── 公理化验证（守恒律/量纲/物理域锚点）
    ├── 语义向量匹配（sentence-transformers）
    └── 风险聚合（critical≥1 → CRITICAL）
    ↓
[CL4] 协调层
    ├── 算力分配：CL0(0%)→CL1(0%)→CL2(30%)→CL3(60%)
    └── 决策：PROCEED / DEGRADE / BLOCK / ESCALATE
    ↓
[L5] 元认知仲裁
    ├── 发散预算控制（动态分配+方向乘数）
    ├── 收敛停滞检测（递减率/连续零产出）
    └── 视角仲裁（5类上下文关键词匹配）
    ↓
[Calibration] 假设校准
    ├── 形式化→可计算形式
    ├── Backend路由（MATLAB/SciPy/Unity/...）
    ├── 执行仿真/优化/求解
    └── 产出CalibrationResult
    ↓
[MCT] 决策树更新
    ├── 回填actual_outcome
    ├── 支撑性重新计算
    ├── 触发重评估（FALSIFIED时）
    └── RazorEngine定期审查
    ↓
[持久化]
    ├── 事实断言层（验证通过）
    ├── 假设推演层（待验证）
    └── 负知识库（已证伪）
```

### 3.2 自指循环：元认知审计

```
MCT决策树
    ↓
MetaAuditor定期审计（每小时）
    ├── 深度审计 → 树过深? → 触发合并
    ├── 置信度审计 → 方差过大? → 触发重评估
    ├── 循环检测 → 支撑边循环? → 标记critical
    ├── 覆盖率审计 → 未质疑前提? → 触发反事实
    └── 时效审计 → 骨架节点过期? → 强制重评估
    ↓
审计报告 → 转为MetaDecisionNode → 入MCT
    ↓
RazorEngine定期审查（每天）
    ├── 归档低支撑性节点
    ├── 合并认知同构路径
    └── 复活被低估分支
    ↓
支撑性追踪更新（每6小时）
    ↓
回到MCT（下一轮审计）
```

## 4. 各层概念设计

### 4.1 CL0：硬约束层（宪法层）

**设计理念**：零概率、零LLM、零解释空间。系统的安全底线。

**核心机制**：
- **多模式量纲系统**：strict / bayesian_float / llm_assisted / full_intelligent
- **后验学习引擎**：记录验证结果，统计误报/漏报，建议容差调整
- **配置数据库**：SQLite持久化，热加载，多版本，变更历史追溯
- **增量验证**：变更范围<20%时只验证子图

**双盘位设计**：
- **硬编码盘**：人工预设规则，变更需全量回测+人工确认
- **软编码盘**：自动发现规则，准入需五道闸门（观察窗口/反例验证/MDL惩罚/影子模式/TTL衰减）
- **晋升通道**：软→硬需180天零误报+3+领域覆盖+不可替代性检验

### 4.2 CL1：近迁移反思层

**设计理念**："历史告诉我们的"。基于已有案例的局部一致性检查。

**核心机制**：
- 历史案例检索（结构化数据匹配）
- 无LLM参与，纯规则驱动
- 依赖注入：可替换验证逻辑

### 4.3 CL2：远迁移思考层

**设计理念**："其他领域告诉我们的"。跨域结构类比。

**核心机制**：
- **CSM三层匹配**：结构匹配(VF2/WL) + 角色对齐 + 语义过滤
- **硬闸门**：锚点数<3或无物理域锚点 → 强制降级CL1
- **ACT-R双权重激活**：ln(freq+1) − λ·ln(Δt+1)
- **降级策略**：无锚点时详细化降级原因

### 4.4 CL3：质疑层

**设计理念**："公理告诉我们的"。从第一性原理出发的挑战。

**核心机制**：
- **公理验证器**：L0元认知 + L4物理 + 守恒律 + 量纲一致性
- **语义向量匹配**：sentence-transformers + 关键词兜底
- **风险聚合**：critical≥1→CRITICAL, warning≥3→HIGH, ≥1→MEDIUM
- **LLM边界审查接口**：预留人工介入点

### 4.5 CL4：协调层

**设计理念**：不是跷跷板，是比例控制器。

**核心机制**：
- **算力比例分配**：CL0(0%)→CL1(0%)→CL2(30%)→CL3(60%)
- **四种决策**：PROCEED / DEGRADE / BLOCK / ESCALATE
- **状态管道**：不可变状态对象，声明式管道执行器
- **依赖注入**：CL0-CL3可全部注入自定义实现

### 4.6 L5：元认知仲裁层

**设计理念**：系统的大脑。何时发散、何时收敛、何时切换视角。

**核心机制**：
- **发散预算控制器**：base × 方向乘数 × 近期折扣
- **收敛停滞检测**：递减率<10% / 连续零产出 / 总产出<3
- **视角仲裁器**：5类上下文关键词匹配（物理/数学/算法/实现/验证）
- **验证反馈循环**：验证结果→权重调整（高/中/低三档）

### 4.7 MCT：元认知决策树

**设计理念**：决策不是日志，是认知资产。

**核心机制**：
- **决策节点**：含前提/选项/推理痕迹/结果追踪/支撑性
- **分叉（Fork）**：新证据产生矛盾时生成兄弟节点，原路径保留
- **回溯（Reassess）**：结果偏差时生成重评估节点，级联标记STALE
- **合并（Merge）**：认知同构路径汇合
- **复活（Resurrect）**：事后评估置信度上升的分支恢复
- **剪枝（Prune）**：归档低支撑性节点（非删除）

### 4.8 校准层

**设计理念**：假设必须可证伪。

**核心机制**：
- **形式化转译**：自然语言→ODE/传递函数/状态空间/优化问题
- **后端插件系统**：MATLAB/SciPy/Unity/BioSim/EconSim
- **统一结果格式**：VALIDATED/FALSIFIED/INCONCLUSIVE/ERROR/TIMEOUT
- **降级路径**：无可执行后端→文献交叉验证→预测追踪

## 6. 关键机制

### 6.1 支撑性（Support）

**定义**：
```
S(D) = |{D' ∈ 活跃决策 : D ∈ premise(D')}| / |所有活跃决策|
```

**等级**：
- **骨架** (>0.5)：系统核心，变更需全量回测+人工确认
- **支撑** (0.1-0.5)：重要但可替代，变更需影响分析+影子验证
- **边缘** (<0.1)：局部决策，可自动重评估

**变更约束**：
- 骨架级变更 → 全量回测 + 人工终审 + 影响范围评估
- 支撑级变更 → 影响分析 + 影子验证
- 边缘级变更 → 可自动重评估

### 6.2 置信度生命周期

```
初始置信度（基于来源/推理类型）
    ↓
CL层验证（硬约束/近迁移/远迁移/质疑）
    ↓
L5仲裁（发散/收敛/视角）
    ↓
校准层验证（仿真/实验/交叉验证）
    ↓
actual_outcome回填
    ↓
偏差判定 → VALIDATED(提升) / FALSIFIED(惩罚-0.3) / INCONCLUSIVE(保持)
    ↓
进入MCT置信度历史
    ↓
Razor Engine定期审查
```

### 6.3 遗忘机制

| 阶段 | 机制 | 触发条件 |
|------|------|----------|
| **审查** | 激活度/引用冗余/邻居覆盖检查 | 定期任务 |
| **Limbo Zone** | 迁入冷存储，查询计数+复活审查 | 审查未通过 |
| **概念退化** | 6层维度迁移到邻居，压缩存储 | Limbo中复活失败 |
| **归档** | 进入decision_archive，不再参与推理 | 彻底过期 |

### 6.4 自指循环

**三层自指**：

1. **规则级自指**：CL0的后验学习引擎记录自身规则的误报/漏报
2. **决策级自指**：MCT的MetaAuditor审计决策树本身的结构健康度
3. **系统级自指**：MetaDecisionNode作为决策进入树，可被再次审计

**限制**：CL0运行时绝不自指（防止递归爆炸），自指仅在Meta-Audit阶段异步执行。

## 8. 边界与局限

### 8.1 当前局限

| 局限 | 影响 | 缓解方案 |
|------|------|----------|
| **形式化转译依赖LLM** | 转译错误可能导致校准错误 | CL0语法检查+人工抽检+影子模式 |
| **校准后端覆盖不全** | 生化/经济领域无内置后端 | 插件化架构，按需添加 |
| **交叉验证是模拟** | 文献交叉验证非真实检索 | 后续接入Semantic Scholar/arXiv API |
| **MCT存储膨胀** | 长期运行节点数爆炸 | Razor归档+归档压缩+快照去重 |
| **支撑性计算O(n²)** | 大规模时延迟高 | 异步更新+增量传播+缓存 |

### 8.2 不可行域

- **实时控制**：认知智流不是实时系统，单次完整流延迟秒级到分钟级
- **创造性突破**：不会提出真正"前所未有"的假设（所有假设来自已有知识的重组）
- **价值判断**：无法判断"这个发现值不值得"（没有价值观模块）
- **因果发现**：只能发现"结构同构"的因果类比，不能从数据中挖掘新因果

### 8.3 最小运行条件

- SQLite可用（~50MB磁盘空间）
- sentence-transformers模型已下载（~80MB）
- Python 3.10+
- 可选：MATLAB（控制/热/机仿真）、Unity（空间物理）

## 一、AI Agent Book 四种存储格式映射

| 格式 | 本质 | 粒度 | 优势 | 劣势 | DialogMesh 映射 |
|------|------|------|------|------|-----------------|
| **Simple Notes** | 最小事实原子 | 1事实/条 | O(1)操作, 极低开销 | 关联丢失, 碎片化 | EntityNode (compiler/) |
| **Enhanced Notes** | 完整叙事段落 | 1段落/条 | 语义完整, 上下文丰富 | 冗余, 难更新, 嵌入退化 | DiscourseBlock.raw_text |
| **JSON Cards** | 三层嵌套分类 | 1卡/类 | 结构化, 部分更新 | 刚性假设, 多维信息丢失 | BeliefMap (v4/cognitive) |
| **Advanced JSON Cards** | 知识管理范式 | 1卡/实体 | person/relationship消歧, backstory溯源 | 成本高, 维护贵 | **XML Memory Cards (新)** ⭐ |

## 二、三层次评估框架

| 层级 | 要求 | 示例 | DialogMesh 覆盖 |
|------|------|------|-----------------|
| **L1 基础回忆** | 存储结构化无歧义信息 | "会员号12345" → 检索正确 | ✅ FactCard + HNSW |
| **L2 多会话检索** | 跨会话综合推理 | 两辆车 → 查询所有车辆 | ✅ 联邦索引(6源并行) |
| **L3 主动服务** | 综合记忆+预见性帮助 | 订国际航班→主动关联护照 | ✅ PlanCard(L4预测) + 温度价值 |

```
│       前沿: LoCoMo L3, 元认知驱动                             │
├─────────────────────────────────────────────────────────────┤
│  L2: 跨会话检索 (联邦索引 — 6源并行)                         │
│       前沿: GraphRAG, HippoRAG, MemGPT                      │
│       我们: RAG并行锚点 + 图扩散 + 温度LRU排序               │
├─────────────────────────────────────────────────────────────┤
│  L1: 单事实检索 (XML Card — 6类型)                           │
│       主流: Simple Notes / JSON Cards / Adv JSON Cards      │
│       我们: XML Memory Cards — 6类型×属性消歧×证据溯源       │
│       优势: XML层次结构 > JSON嵌套, LLM原生理解              │
├─────────────────────────────────────────────────────────────┤

│       主流: SQLite / PostgreSQL / Redis                      │
│       我们: LSM(WAL+mmap+5CF) + SHA256链 + Rust编译         │
│       优势: 事件溯源审计 + JVM-GC tiering + 批量优化         │
└─────────────────────────────────────────────────────────────┘
```

## 五、与主流方案的竞争力分析

| 维度 | MemGPT | Mem0 | GraphRAG | **DialogMesh** |
|------|--------|------|----------|----------------|
| 存储格式 | Flat text | JSON Cards | Graph nodes | **XML Cards (6类型)** |
| 关系消歧 | ❌ | ❌ | ✅ 图结构 | **person/relationship属性** |
| 事件溯源 | ❌ | ❌ | ❌ | **SHA256链** |
| 温度/价值 | ❌ | ❌ | ❌ | **P×I 2D路由** |
| 检索 | embedding | embedding | 图扩散 | **联邦索引(6源并行)** |
| 元认知 | ❌ | ❌ | ❌ | **关系聚类→规则凝练** |
| 评估框架 | ❌ | ❌ | ❌ | **待实现** (可学LoCoMo) |

**唯一缺口**: 缺少类似 LoCoMo 的自动评估集。其他维度持平或超越主流方案。

## 二、注入点颗粒度——变体空间（不是硬约束, 2026-08-15 修正）

> 修正（用户拍板）: 蓝图语义 = 多样性 + 选择机制, 不是单一路径。
> 每个注入点提供**变体档位**（默认值 + 备选）, 由消融量化 + 意图级
> 配置 + 用户白盒选择决定; 实现不承诺"最优", 承诺"可选"。
> 唯一不可协商项: **原文存在性**（P9: full_text 必须保留, 摘要/预算
> 只影响注入, 不影响存在）。

| 注入点 | 变体档位（默认加粗） | 选择机制 |
|---|---|---|
| 锚点展示（format_anchors） | 160 / 300 / 600 | DM_ANCHOR_CHARS; 前端可调 |
| 召回 hit.text | 200 / 400 / 全文 | 展示粗扫, 不影响 full_text |
| **召回 hit.full_text** | **全文（必存）** | P9 承诺, 不可协商 |
| llm_reply 结构节点 | 200 / 400 | 无细节价值, 低档 |

| 工具结果（file_read/web/pdf） | **2000** / 500 / 全文 | DM_TOOL_DETAIL; 按工具类型 |

## 三、价值判定算子（P9 可操作化, 设计细节空白补丁）

"低概率高价值"的工程判定（启发式, 后续可学）:
- 概率轴: 该块/主题在检索中的出现频率（同主题块多 → 高概率低价值
  → 允许摘要化）; 唯一/罕见内容（代码、数字、具体结论）→ 低概率
  → 全文保留。
- 价值轴: 能否被现有模型解释（A7 判据）— 解释不了 = 新信息 = 保留;
  能解释 = 平庸 = 可凝练。
- 工程落点（当前）: 详情类键（anchors/compiled_subgraph/tool_result/
  response）自动走大预算; 结构类键走 200。后续按访问频率/检索频率
  学价值分。

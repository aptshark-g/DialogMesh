## 二、已拍板决策（2026-08-01，§14）

1. **产出形态** = 坐标(XYZ/zone) 给算法 + 罗盘标签(温度/距离/价值) 给 LLM，两者融合
2. **维度** = 声明式注册、可插拔、权重可配置（不硬编码）
3. **切分** = 三阶段渐进: PCR 粗切(输入时) → LLM 回答期间关联链细化(异步) → LLM 后验维护
4. **子图** = 双向: PCR 决定子图口径(选域)，子图反哺 PCR 坐标(预期上下文先验)
5. **关联链** = 双向: PCR 是 L3 粗处理，关联链凝练规则辅助 PCR；关联链是 NLP 核心
6. **X 轴** = 混合保留(nomic cos+IDF+entity_density)，调权重不删维度
7. **验证** = 做完再检验；旧测试恒真断言="作假"，需重做

## 六、补充拍板（2026-08-01 第二轮）

8. **子图反哺 = C/S 架构（被动）**: PCR 是客户端，主动开通道拉取子图/关联链的"预期上下文"，子图/关联链作为服务端回应。非事件订阅/推送
   - 优点: 解耦清晰、时序可控(主动拉取天然防死循环)、降级明确(拉不到→纯结构坐标兜底)
   - 协议: 请求=子图口径(域/预算)，响应=预期上下文先验(坐标偏置)
   - 约束: 同轮只拉一次 + 超时降级
9. **罗盘标签 vs 坐标 = 并列计算(各自独立产出)**: 坐标给算法路由，标签给 LLM 导航，互不推导
   - 冲突处理: 不裁决(服务对象不同)，记录冲突供后验
   - 成本: 复用坐标中间结果(结构特征/距离)，非全量重复计算

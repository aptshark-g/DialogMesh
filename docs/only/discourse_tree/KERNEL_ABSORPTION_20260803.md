## 一、核心判断：推理 vs 记忆的平衡 = 职责分离

### 1.1 为什么"没统一好"（阶段三审计结论）
- v1/v2 把对话树做成了"自带记忆功能的推理树"——把 A15 的活（温度/摘要/压缩）硬塞进 A5 的模块（v2 自己 `build_llm_context` 直接给 LLM）；
- 链01 修正反着偏——把对话树降级成"ContextCompiler 数据源"，丢了推理属性（位置信号/焦点管理/推导链）只留"供数据"；
- 两份设计各偏一端，没有一份回答："对话树到底干什么，不干什么"。

### 1.2 公约给出的答案（A5 × A15 互补关系，原文）
> "树的**激活计数**管推理焦点（当下该想什么）；**温度系统**管记忆驻留（该以什么粒度存在）。一个在内存推理侧，一个在持久化存储侧。"

```text
推理侧（对话树内核，A5）                记忆侧（温度/持久化，A15）
─────────────────────────────          ─────────────────────────────
树结构 + 位置信号（你在哪）              多因子温度场（时间×访问×主题×语义唤醒）
焦点管理（当前该想什么）                 颗粒度驻留（Hot 原文→Frozen 索引）
推导链（怎么走到这里的）                 摘要 = 换缩放级别（A2/P11）
跨分支指针（Tree-Graph Hybrid）         语义唤醒（BGE>0.8 回 Hot）
─────────────────────────────          ─────────────────────────────
           │ 接口：块 × 缩放级别建议（不亲自做摘要压缩）
           ▼
     ContextCompiler / 子图 / 主题树（下游消费）
```

**一句话**：对话树是推理工作台，负责"想什么"；记忆驻留是温度系统的活，负责"以什么粒度存在"。对话树对记忆只暴露**接口**（这个块该用哪个缩放级别），不做记忆的活。

## 三、内核数据契约（草案）

```text
输入（Event 层）:
  用户输入/行为事件
  + 可选先验: PCR 意图信号（expectation/noise）· 画像偏置（P4 双向先验）

Stage 1  HeaderInjector    指代补全（头文件引入，纯规则 <1ms）
Stage 2  SyntacticDecomposer  → List[EDU]（含 ParsedClause 骨架）
Stage 3  MacroMicroQuantizer  双维量化 → CohesionScore

决策（路由）:
  快路径: 单阈值极端区（>0.75 continue / <0.25 fork）——零 LLM
  灰区:   四象限（attach 落地）+ 长证明后验（A13 跨轮累积，达阈值结晶；
          有限轮不收敛 → 最大熵默认 + 主动询问）

树（推理内核）:
  DiscourseBlock（位置信号: depth/path/焦点指针）
  + cross_ref / group_ref（Tree-Graph Hybrid 指针，关系第一公民 A3）
  + 激活状态（激活计数驱动，电容模型 A5）

输出（Observation 集合，不是结论 — P1）:
  ① 块级结构        → 主题树 / 子图 / ContextCompiler（链01 数据源）
  ② 缩放级别建议     → 温度系统（"该块用哪个缩放级别"，不自己压缩 — A15 接口）
  ③ 焦点/激活状态    → 行为链（预测协同）/ 元认知（审核/复盘）
  ④ 决策 trace      → git 式记录（A17，split/merge/promote 全 diff）
```

### 关键契约变化
1. `ingest_turn` 统一为「原文 + 可选先验 → 块级结构 + 缩放建议」——不再要求调用方传 parsed_clauses/cohesion_scores（B 的实现证明那套契约没人用）；
2. 四象限 `attach` 决策落地（v2 §5.2 设计、零实现）；
3. 温度从"状态字段"变"对外接口"——对话树暴露 `block.zoom_level(温度场输入)`，压缩由记忆侧执行；
4. 决策阈值全部进参数注册表（A18），黄金示例集先行（PCR 教训）。

## 五、推理-记忆平衡的具体化（讨论核心）

结合用户历史拍板（PCR 协同 + 子图 C/S + 罗盘式）：

```text
Round N:
  Fast  → PCR 粗切分（Event 层粗切）→ 对话树建块（粗结构 + 位置信号）
```

**平衡点三问（供拍板）**：
1. 对话树做不做摘要？——建议：只做轻量 v1-v3（配合 A16 快速反馈与检索锚点），v4 命题压缩交给记忆侧（A15 换表示）；

3. 灰区决策？——单阈值快路径 + 四象限灰区走 A13 长证明后验，跨轮收敛，不无限累积。

## 八、第一公理：短期认知缓存假说（树图双模态）— 2026-08-03 讨论拍板

> 来源：用户讨论（2026-08-03）"我假定了人短期的内容是存在方向性的有规律的，这个是对话树的核心" + "对话树并不是真的是树，实际上是树图，模拟大脑 ECN 记忆组块，思考时树为核心，发散/变化时是图，组块范围被主题概念抽象化"。
> 地位：对话树内核的**第一性原理**——比"推理树 vs 记忆树"更底层，同时解释"为什么是树"与"为什么是缓存"。

### 8.1 公理表述

```
短期认知 = 树图双模态（Tree-Graph Hybrid，非树+指针折中）
  组块内（思考时）: 焦点栈沿推导方向移动 — 树（收敛/深挖，有向）
  组块间（发散时）: cross_ref 联想跳跃 — 图（发散/变化，无向）
  组块边界 = 方向性断裂处 = "主题"概念的形式化抽象

对话树的有效域 = 短期 + 组块内方向性成立
域外一律不背:
  长期规律  → 行为链 / 图 / 持久化（行为模式跨会话，非短期方向性）
  LLM 推理  → Cognitive Tree（LLM 思考无人脑短期方向性约束，可并行/跳跃）
  跨会话关联 → 子图 / 记忆系统
```

### 8.2 为什么这个公理成立（认知科学支撑）

| 依据 | 内容 | 对应 |
|---|---|---|
| 工作记忆组块 | Miller 4±1 / Cowan：短期容量有限，以当前焦点为中心组织 | 组块 = DiscourseBlock |
| 注意力状态 | Grosz & Sidner 焦点栈：深挖=入栈、切换=换栈、回溯=栈内定位 | 组块内树的方向性 |
| 局部连贯性 | TextTiling/LCseg 可work 的前提：相邻轮次延续当前话题 | 组块边界=话题切换 |
| ECN 记忆组块 | 加工单元（有向推导）+ 上下文切换（联想跳跃） | 树图双模态 |

### 8.3 公理同时解释的两个直觉

- **为什么是树**：方向性是"组块内"的性质——树是方向性的数据结构（位置信号/焦点/推导链）。图没有方向，文本流没有层。
- **为什么是缓存**：短期性 = 时间局部性（最近活跃）+ 空间局部性（同话题邻近）——温度系统 + 话题分组。对话树 = "有方向性的短期缓存"，记忆直觉与结构直觉在此统一。

### 8.4 关键推论（自带的退化路径）

1. **树的纯度不是设计选择，是组块内方向性强度的函数**——若黄金示例集测出用户组块间跳跃极频繁 → 树退化为"图优先 + 弱树骨架"；反之树优先。
2. **组块边界由方向性连续性决定**，主题标记只是给边界起的可解释名字（`topic_markers` 77 标记是形式化实现，非本质）。
3. **Cognitive Tree 不糅合**：两种方向性（人脑短期 vs LLM 推理）塞一棵树会互相污染位置信号——推理单独存在有独立价值。
4. **行为链不背**：行为规律是长期属性，嵌入短期结构会破坏缓存命中率。
5. **域外交给谁**：长期→行为链/图/持久化；推理→Cognitive Tree；跨会话→子图/记忆系统。

### 8.5 P0 验证项（A18 真实断言，黄金示例集三测）

| # | 命题 | 验证方法 | 若失败 |
|---|------|---------|--------|
| V1 | 相邻轮次 cohesion 显著高于随机基线 | 黄金示例集：方向性存在 | 对话树无根，改图优先 |
| V2 | 焦点栈模型可预测"回到刚才那个"的定位 | 回溯场景命中率 > 基线 | 方向性不可结构化为树 → 强 cross_ref/图 |
| V3 | 用户回溯符合 LRU/时间局部性 | 回溯目标在最近活跃集合内的比例 | 缓存模型不成立 → 弱化温度系统 |

> 三条全过 → 对话树有根（树优先 + 缓存成立）；V2 失败 → 树退化为"树骨架 + 强图联想"；V3 失败 → 温度/摘要简化。验证结果直接决定内核树纯度。

### 8.6 对内核契约的影响

- 内核保留：树（组块内方向性）+ cross_ref（组块间联想）+ 温度（短期缓存）——三者都是公理的直接实现
- 内核不背：行为链/因果链内嵌（长期注解）、Cognitive Tree（LLM 推理）、长期记忆（图/持久化）
- 主题 = 组块边界抽象：切分算法的本质是"找方向性断裂处"，不只是"找话题词"

## 九、摘要定位：个体化记忆痕迹（公理在摘要维度的推论）— 2026-08-03 讨论拍板

> 来源：用户讨论（2026-08-03）"摘要蛮重要的，子图扩展不能总在持久化里；RAG+图搜索是加强召回质量，对话树是对这个质量的再提纯；对话树试图模拟个体化的记忆组块，在记忆上同频"。

### 9.1 核心命题

```
RAG 假设:  LLM 能理解个体化 → RAG 只负责信息增强
对话树假设: 模拟个体怎么记这段对话（组块/话题/重点/转折）
           → 在记忆上同频 → LLM 站在用户记忆组织方式上推理

摘要 ≠ 压缩工具
摘要 = 个体化的记忆痕迹（用户回忆该话题时的概括方式）
       vs A15 通用压缩（温度驱动的降维换表示，对谁都一样）
```

### 9.2 为什么摘要重要（三层角色）

| 角色 | 机制 | 与 RAG 的差异 |
|---|---|---|
| 子图扩展素材 | 对话树缓存提纯过的短期规律 = 子图扩展的 L1 热缓存（近/热）；持久化 = L2（远/冷）| RAG 直接回持久化粗召回；对话树就近取提纯结果 |
| 召回再提纯 | RAG/图搜索 = 粗召回（质量增强）→ 对话树 = 精提纯（按用户记忆痕迹过滤/重组/浓缩）| 一级粗筛 + 一级提纯，不是替代是级联 |
| 记忆同频 | 给 LLM 的组织方式 ≈ 用户记忆的组织方式 | RAG 给"关于对话的信息"；对话树给"对话在用户记忆里的样子" |

### 9.3 对内核契约的修正

- **对话树应该做摘要**（修正 8.6/§七 2 中"不亲自做摘要"的倾向）：做的是**个体化记忆痕迹**（行为链/偏好/反复出现的模式/关键转折），不是 A15 通用压缩
- v2 的 v1-v4 分级方向正确（首句→实体→演化→命题），实现偷懒（简化成"实体+动词"）需按记忆痕迹标准重做
- 与行为链的边界：摘要含用户行为痕迹（个体化），但行为链本体仍是独立长期数据源（注解层）——摘要引用行为链的痕迹，不内嵌行为链
- 子图扩展路径：ContextCompiler 取域 C 时，优先对话树提纯块（L1），不足再回持久化（L2）——RAG 粗召回 → 对话树提纯 → 子图编译 → LLM

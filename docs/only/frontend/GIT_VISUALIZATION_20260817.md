# 内置 Git 可视化 + 环境信息面板（2026-08-17 立项）

> 状态: 环境信息面板 P0 已实现; 内置 git 可视化 / VS 联动为待办
> 触发: 用户「工程链副屏改环境信息: 变更/远端/分支/提交/git 可视化/skills/
>  项目关系约束/图关系/本轮修改内容（可能需与 VS 绑定）」

## 一、已实现（P0, 全部实测）

- **后端只读端点** `GET /v6/git/status`（`core/agent/api/git_api.py`）:
  分支 / 远端 URL / 领先落后 / 暂存·未暂存·未跟踪计数 / 最近提交
  （hash·message·date·author）/ 变更文件列表（前 30）/ dirty 标记。
  全部 git 调用只读（rev-parse/status/log/remote）, 无任何写操作（A21）。
- **工程链副屏 → 环境信息**（DockContents `EnvironmentDockContent`, 原
  占位 raw dump 替换）: Git 工作区卡（分支/前后/变更数/远端/最近提交/
  变更文件清单）+ 已启动 Skills（/v6/skills）+ 项目关系约束（/v6/engineering
  约束计数, 引用博客 chapter2 关系约束案例）+ 项目图关系（/v6/graph 节点/
  边/子图锚点）+ 手动刷新。
- 工程页模块点击 → 副屏切「节点详情」摘要（默认副屏 = 环境信息）。
- 相关: 项目页顶部加「新建会话」（B16 创建即归属项目）+ 修复创建时间
  显示（epoch 秒 → 毫秒）。

   前端: 环境信息面板内嵌提交图 + 变更文件点击看 diff 摘要。

   c) 对外暴露 JSON 给 VS 扩展消费。
   建议先做 (b)（零依赖, 与 git 面板同源）, (a)(c) 排后。
3. **项目关系约束增强**: 把 chapter2 关系约束案例落成项目级可编辑约束

## 三、验收标准（A18 真实验证）

- git 面板数据与 `git status`/`git log` 真实一致（不造假值）。
- 无写操作端点（git 侧全部只读, 提交/分支切换走已有 CLI/网关, 不进面板）。
- tsc/build 绿 + 端点测试绿。

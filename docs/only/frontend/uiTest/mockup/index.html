聊天 / FxLMS 高频段收敛问题
你15:42
FxLMS 在 200Hz 以上的窄带扰动收敛明显变慢,步长已经调到稳定上限了。可能是什么原因?
DialogMesh15:42

两个最可疑的方向:

  1. 次级通道估计 Ŝ(z) 的高频相位误差。200Hz 以上相位滞后一旦接近 90°,Filtered-X 结构的有效步长会被急剧压缩,表现为"没到发散阈值但几乎不收敛"。
  2. 环路总时延。如果 FPGA 流水线 + ADC/DAC 的总时延接近采样周期的 1/4,高频段参考信号与误差信号先去相关,收敛速率随频率平方下降。

建议先重跑一次次级通道辨识,看 200–400Hz 的相位裕度,再决定是否压缩流水线级数。

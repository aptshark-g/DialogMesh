> 触发: 用户系统性指出多处前端粗糙/占位/不可用; 本轮修一部分, 其余排期。

## 一、本轮已完成

- **副屏滚动修复**: DockPanel / RightDock flex 链补 `min-h-0`（经典 flex 滚动失效）;
  副屏圆角 `lg:rounded-dock`（未定义类）→ `lg:rounded-2xl`; 玻璃材质
  `glass-panel-strong` 确认存在。
- **图谱意图过滤**: 后端 `kernel_graph` 把 v3 遗留意图（scan/read/write memory,
  hack_value, explain 等）归一化到现行分类（cross_domain_ir:
  TASK/QUERY/CORRECTION/DISCUSSION/CASUAL/TOPIC_SWITCH）; 前端
  `INTENT_COLOR_MAP` 换新分类 + 中文标签（任务/查询/修正/讨论/闲聊/话题切换/未知）;
  页面用 `node.intent`（type 仅兜底）。
- **画像 OCEAN 中文标签**: o/c/e/a/n 代号 → 开放性/尽责性/外向性/宜人性/神经质
  （CognitiveProfilePage + ProfileEditPanel）。
- **工程链页重排**: 递归地图 → 工具与技能 → 约束编辑 → 工程约束数据摘要 →
  工程模块（最底, 滚动增量加载 10/批, 编辑态按钮圆角）。
- **网关**: 路由模式卡片可点击切换（setRouterModes + route_stats 展示）;
  用量页加 Token 用量柱状图（按模型 输入/输出, recharts）。

## 一·五、第二轮已完成（2026-08-18 续）

- **画像 OCEAN 修复（上轮未生效根因）**: API 维度键实为单字母
  O/C/E/A/N + NC/CS/DK/MS/CL（10 维）, 上轮映射只写了全名 → 本轮补单字母
  映射 + 中文（开放性/尽责性/外向性/宜人性/神经质/认知需求/沟通风格/
  领域知识/元认知/好奇心）。
- **路由切换修复（上轮不可用根因）**: 后端只有 GET 无 PUT（405）且
  `_router_v4` 从未实例化 → 新增 `kernel_set_router_mode`（持久化
  data/router_mode.json + 存根同步）+ PUT /v6/router/modes; 实测切换生效。
- **网关用量时间轴**: `GET /v6/gateway/usage/series` 聚合 switch
  `usage_log.jsonl`（真实路径 DialogMesh/gateway/usage_log.jsonl）按日期
  输出输入/输出/费用; 前端图表 X=日期, 输入+输出堆叠柱。实测 6 天真实数据。
- **管道页可读化**: 页面说明（认知流水线五层 + 本页控制什么, 「关于」悬浮）+ 运行模式
  （自适应/固定 + 自适应步长）+ 参数变更记录（会话内 from→to 时间线）。
- **深层链可读化**: 「关于」悬浮逐 tab 解释（关系底物/因果链/行为图/工程约束/
  信念状态/编译子图）。
- **关于悬浮**: 新增 AboutPopover 组件（小按钮 + 悬停玻璃弹层）, 替代固定说明卡。

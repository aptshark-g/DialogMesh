## 一、B1 图谱编辑版本化（同型推广）

### 问题
ConversationGraphPage 的图谱/对话树/语义对象编辑（/v6/edit/*）直接改引擎对象,
无版本号 — 与 task_graph 同型的"状态刷新吞操作"风险（多端并发编辑后写覆盖先写）。

### 后端（api_viz_edit.py + kernel/dispatch.py）
- 共享版本号 `engine._viz_version`（内存态=热, 懒初始化 0）
- 辅助: `_viz_version()` / `_bump_viz_version()` / `_guard_viz_version()`
  （请求带 version 且落后 → 409 `{error: version_conflict, current_version}`）
- 5 个编辑端点全部接入: graph / discourse-tree / objects / relations / ir
  （请求模型加 `version?: int`; 入口校验; 成功修改后 bump）
- 4 个 GET 端点返回 version: /v6/graph /v6/discourse-tree /v6/objects /v6/relations

### 前端
- `types/api.ts`: 4 个 Response + 5 个 EditRequest 加 `version?: number`
- `api/v6.ts`: `VizConflictError`（409 结构化）+ apiFetch 统一识别 409
- `ConversationGraphPage`: `versionRef`（随 graph.version 同步）; 编辑带 version;
  409 → 冲突提示条（amber）: **覆盖服务端**（强制不带 version 重发）/
  **加载最新**（refresh）

### 验证
- 新增测试 `test_viz_versioning.py` **5/5 全绿**（强制覆盖/递增/过期 409/
  跨端点共享/kernel version）

## 二、B6 RightDock 三屏结构

  （clamp 280–560 + localStorage `dm_sidepanel_width` 持久化, 初始宽度恢复）
- `DOCK_TITLES` 内容标题映射

### SidePanel（ui/SidePanel.tsx）
- 左边缘拖拽 resize handle（onPointerDown/move/up, clamp, 持久化）

### RightDock（新 components/dock/RightDock.tsx）
- 头部 tab 切换 6 种内容（图标 + 文字, 2xl 以上显示文字）
- **auto 联动**: 路由 → 默认内容（/graph→图例, /task-planning→任务,
  /engineering→工程链, /pipeline→上下文, /chat→画像, 默认画像）
- **fixed 模式**: 用户手动点 tab 自动转 fixed; 顶部 mode 开关可切回 auto
- 收起按钮 + 标题跟随内容

### DockContents（新 components/dock/DockContents.tsx）
- `ProfileDockContent`: 原 RightPanel 主体（雷达/卡片/进度, useV6Profile 真数据）
- `ContextDockContent`: /v6/context 真数据（意图域/条目/tokens）
- `EngineeringDockContent`: /v6/engineering 真数据
- `TasksDockContent`: taskStore 概览（节点/连线/执行状态）
- `LegendDockContent`: 图谱图例（节点类型/温度/操作说明）
- `ThinkingDockContent`: 占位（待接线, 与 DeepChain 共享事件源）

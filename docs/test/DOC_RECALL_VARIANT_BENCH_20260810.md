## 关键结论

1. **跨语言召回修复**（本轮核心）: en top1 0% → 24%（MRR 0.063→0.355）
   - 根因 1: 中文 BGE-zh 512 维 vs 英文 multilingual 384 维 → 维度不匹配
     → 方案 C: BGE-M3 统一 1024 维（models/models/BAAI--bge-m3, 2.27GB）
   - 根因 2: 词法粗筛对英文 query 是盲区（正确中文块进不了候选）
     → coarse_candidates 加向量粗筛（词法 ∪ 向量）
   - 根因 3: BM25 对非中文 query 假高分（ASCII 术语碰巧匹配压过向量）
     → _bm25_anchors 跨语言保护（非中文 query 跳过 BM25）
2. **中文 tradeoff**: 原查询 22% vs bge-small-zh 32%（-10pp）
   - bge-m3 单语中文弱于专用中文模型（跨语言收益 vs 中文损失）
   - 待决策: 保持 bge-m3 统一 / 双语双索引（zh 用 bge-small + en 用 bge-m3）
3. **性能修复**（评测超时根因）:
   - semantic_encoder 联网下载模型重试（15s+/query）→ 本地优先, 联网禁用
   - _save_index_cache 每次 query 全量 json.dump（6.7s/5query）→ 异步+节流
   - 评测耗时: 900s 超时 → ~350s（含编码）/ ~190s（纯打分）
4. **速度基线**（Rust 化动因）:
   - 全库扫描单 query: 215s（10969 块纯 Python 余弦循环）
   - top_c=200 粗筛单 query: ~1.1s（稳态）; 向量粗筛 +0.5s/query
